# AI-Powered Workplace Productivity Assistant

## Overview
This repository contains a suite of structured AI prompts and workflows designed to automate and streamline core workplace tasks.

## Assistant Capabilities
1. **Email Generation** – Crafting clear, professional client and internal emails.
2. **Meeting Summarization** – Converting raw notes into key takeaways and action items.
3. **Task Planning** – Breaking down complex projects into actionable steps.
4. **Research Assistance** – Synthesizing articles and summarizing workplace topics.
5. **Chatbot Interaction** – System prompts for a specialized workplace assistant persona.

## Tools Used
- GitHub
- AI Models (ChatGPT / Gemini / Claude)

## Ethical Considerations
- Human review and verification before sending communications.
- Data privacy and confidentiality.
